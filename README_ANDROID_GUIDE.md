# دليل بناء وتثبيت تطبيق حارس قفل الشاشة على أندرويد 13

أهلاً بك! لقد تم تصميم هذا المشروع البرمجي ليعمل كـ **حارس حقيقي متكامل** على نظام أندرويد 13 و 14 مستوفياً كافة الشروط الأمنية لنظام أندرويد الحديث.

## كيف يعمل التطبيق بنجاح على أندرويد 13؟
1. **DeviceAdminReceiver (مسؤول الجهاز)**:
   - يستمع مباشرة لأحداث نظام قفل الشاشة عبر سياسة `watch-login`.
   - عند إدخال كلمة مرور أو رمز PIN أو نقش خطأ، يُطلق نظام أندرويد حدث `ACTION_PASSWORD_FAILED`.
2. **CameraCaptureService (خدمة الكاميرا الأمامية)**:
   - تستخدم مكتبة Google CameraX للوصول إلى الكاميرا الأمامية (`LENS_FACING_FRONT`).
   - تلتقط الصورة خفية بدون فتح تطبيق الكاميرا أو إزعاج المستخدم.
3. **تجاوز إيقاف البطارية (Battery Whitelist)**:
   - يطلب التطبيق تصريح `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` لكي لا تقوم واجهات شاومي أو سامسونج بإيقاف الخدمة عند نوم الهاتف.

## خطوات البناء عبر GitHub Actions (سحابياً بضغطة زر):
1. حمّل ملف `LockGuard-Android13-Complete-Project.zip` من التطبيق.
2. فك الضغط عن الملف وارفع محتوياته إلى مستودعك على GitHub.
3. توجه إلى تبويب **Actions** في صفحة مستودع GitHub.
4. ستجد البناء بدأ تلقائياً! بعد دقيقة واحدة سيظهر باللون الأخضر ✅ وستجد ملف الـ APK جاهزاً للتحميل في قسم Artifacts!
